This is the repository of Eidos(https://github.com/mayneyao/eidos) resources created by me

Task.eidos is a "template" to use Eidos as a personal task management.

Notas.eidos is an eidos file with my initial "template" to use Eidos as a note-taking app.

It uses the " davi.folders-view" (you can download here),  a plugin that turn the tags field in "folders". In fact it's just visual. (https://github.com/mayneyao/eidos/issues/415)

By now I'm using the file tree , markdown files and folders of my Space so I have no intention of further maintain or improve it. 

Feel free to fork this repo or just download and make it better to you and others. Please let my know if you do that.

My homepage https://davi-jorge-art.carrd.co/

The Tasks.eidos file is what I actually use. My work flow : Separate all tasks with a few labels (with deadline, important, and a few more...). Prioritize. Determine what I need/can do today, reprioritize at the end of the day.
